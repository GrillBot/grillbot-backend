# Contributing

Contributions are welcome. Open an issue first for anything larger than a small
fix, so the direction can be agreed before you invest time.

## Licence of contributions

GrillBot is licensed under the [MIT License](LICENSE). By submitting a pull
request you agree that your contribution is licensed under the same terms
(inbound = outbound). There is no CLA and no copyright assignment: you keep the
copyright to your work.

Only submit code you wrote yourself or code whose licence allows distribution
under MIT. Do not paste in GPL/AGPL code or assets you do not have the right to
share.

## Dependencies

New third-party packages must be permissively licensed (MIT, Apache-2.0, BSD or
similar) and added once to `Directory.Packages.props`. List anything that needs
attribution or is not plain MIT in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
Do not add copyleft (GPL, AGPL) or commercial dependencies.

## Reporting problems

See [SECURITY.md](SECURITY.md) for vulnerabilities and use the issue templates
for bugs and feature requests.
